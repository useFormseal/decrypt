# Getting started

Install formseal-decrypt and start decrypting form submissions.

## Installation

### From PyPI (recommended)

```bash
pip install formseal-decrypt
```

Or with pipx:

```bash
pipx install formseal-decrypt
```

### From source

```bash
git clone https://github.com/useFormseal/decrypt.git
cd decrypt
pip install -e .
```

### Verify installation

```bash
fsd
```

## Quick start

### Step 1: Connect to your ciphertexts

```bash
fsd connect
```

You'll be prompted for:
- **Source file** — your ciphertexts (e.g., `formseal.ct.jsonl`)
- **Destination directory** — where decrypted files go
- **Private key** — your private key from formseal-embed setup

You can also provide everything non-interactively:

```bash
fsd connect source:ciphertexts.jsonl destination:. private-key:YOUR_KEY
```

> In interactive mode, if the source file doesn't end in `.jsonl`, it's appended automatically. Non-interactive mode does not auto-append.

### Step 2: Decrypt

```bash
fsd decrypt
```

This decrypts all ciphertexts and writes `formseal.decrypted.jsonl` (canonical ledger). Pass `--format` for an additional export:

```bash
fsd decrypt --format csv
fsd decrypt --format json
fsd decrypt --format md
```

> Each `fsd decrypt` run **overwrites** all output files — it does not append.

### Step 3: Check status

```bash
fsd status
```

Shows your source, destination, key location, entry counts, and last decrypt timestamp.

### Step 4: Disconnect (when done)

```bash
fsd disconnect
```

You'll be prompted to confirm (`y/N`). Use `fsd disconnect --wipe` to also delete decrypted files.
